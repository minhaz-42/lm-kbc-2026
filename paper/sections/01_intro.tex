\section{Introduction}
Pre-trained language models (LMs) store a remarkable amount of factual knowledge
in their parameters, acquired during pre-training on large text corpora
\citep{petroni2019lama,roberts2020closedbook}, and a body of work probes and
extracts it \citep{jiang2020lpaqa,zhong2021optiprompt,alkhamissi2022review}. This
raises the prospect of building a structured knowledge base (KB) directly from an
LM rather than from curated sources \citep{dong2014knowledgevault,vrandecic2014wikidata}:
no schema engineering, no hand annotation, and an open query set. Doing so
reliably, however, is harder than answering a single factual question. A KB entry
is a \emph{complete set} of facts, so the model must decide not only what is true
but how many objects, possibly none, a subject and relation admit.

The LM-KBC~2026 shared task \citep{alivanistos2022prompting,kalo2023lmkbc,kalo2025lmkbc}
formalises exactly this: given a subject $s$ and relation $r$, predict the complete
object set $\{o_1,\dots,o_k\}$, where $k$ may be zero, one, or many
(Section~\ref{sec:task}). Predictions are scored by macro precision, recall, and
F\textsubscript{1}, with string normalisation and alias matching for entities and
a 5\% tolerance for numeric relations. The central difficulty is that this is not
single-answer probing: unlike benchmarks such as LAMA \citep{petroni2019lama},
which assume exactly one gold object and reward ranking it highly, this setting
demands the \emph{entire} set, and the empty set is a legitimate, frequent answer
(a living person has no recorded city of death; an island country has no land
border). Three difficulties follow. LM outputs are stochastic and prompt-sensitive,
so a single query yields an unstable set; relations span very different
cardinalities, from a single number to hundreds of award recipients, which
complicates aggregation; and the model must recognise when it does not know an
answer and \emph{abstain} rather than fabricate one. The 2026 edition compounds the
challenge by being strictly \emph{closed-book}: a system may use any open-weight
model up to 32B parameters, but no web search, no retrieval, no external corpus,
and no fine-tuning. This forecloses the retrieval and tuning that strong entries in
earlier editions relied on \citep{zhang2023llmke,asai2024selfrag}, leaving
parametric recall and prompt design as the only levers.

In this paper, we start from the evaluation metric itself rather than from the
model. Because macro-F\textsubscript{1} scores an empty prediction against an empty
gold set as perfect, simply predicting nothing everywhere already attains $0.175$
relation-averaged macro-F\textsubscript{1} on validation, competitive with the
official baseline ($0.273$) and higher on the most null-heavy relations
(Section~\ref{sec:task}). The lesson is that points come not from answering
everything, but from recalling the few numeric values and, above all, from knowing
when \emph{not} to answer. We therefore make abstention a first-class decision that
addresses the incompleteness and hallucination difficulties above directly: for
each null-heavy relation we take several samples and keep an object only when the
samples agree, collapsing to the empty set when the model is internally
inconsistent. Scope-grounded prompts and median-of-samples aggregation for numeric
relations complete the pipeline (Figure~\ref{fig:pipeline}).

Our system handles all six relations of the task, spanning entity-valued relations
(\textsc{countryLandBordersCountry}, \textsc{personHasCityOfDeath},
\textsc{companyTradesAtStockExchange}, \textsc{awardWonBy}) and numeric relations
(\textsc{hasCapacity}, \textsc{hasArea}), with a per-relation strategy that pairs
each prompt with the relation's official scope and induces abstention from the
generated set (Section~\ref{sec:method}). Our headline model is Gemma-4-31B, a
30.7B open-weight model that is the strongest within the 32B budget; we also report
a Qwen2.5-14B (14.7B) system run locally in 4-bit, and study decode-time
self-consistency voting as an ablation (Section~\ref{sec:setup}). Because all
generation is cached, the entire decode, aggregation, and abstention stage is a
deterministic function of the cache that runs without a GPU, so it can be tuned and
reproduced offline.

This paper makes three contributions. First, a metric analysis
(Section~\ref{sec:task}) shows that under the macro metric abstention is a
high-value action: the predict-nothing baseline already rivals the official
baseline and beats it on the most null-heavy relations, which reframes the task
around \emph{when to answer}. Second, we build a per-relation pipeline
(Figure~\ref{fig:pipeline}, Section~\ref{sec:method}) that grounds prompts in exact
scopes and induces \emph{calibrated abstention} via self-consistency voting, with
no trained confidence model; it lifts a weak 0.5B model from $0.173$ to $0.372$ on
the null-heavy relations, clearing the predict-nothing floor rather than merely
matching it, and still helps a strong 14B. Third, the resulting open-weight system
reaches $0.459$ relation-averaged macro-F\textsubscript{1} ($0.490$ micro) with
Gemma-4-31B, beating the official baseline ($0.273$/$0.284$) on all six relations
and clearing the empty baseline ($0.175$) by a wide margin; a local 4-bit
Qwen2.5-14B reaches $0.416$/$0.447$ under the same pipeline, and comparing it
against Gemma-4-31B shows that at this budget model scale outweighs decode-time
self-consistency (Section~\ref{sec:analysis}).
