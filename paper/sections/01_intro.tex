\section{Introduction}
Pre-trained language models (LMs) store a remarkable amount of factual knowledge
in their parameters \citep{petroni2019lama,roberts2020closedbook}, and a body of
work probes and extracts it \citep{jiang2020lpaqa,zhong2021optiprompt,alkhamissi2022review}.
This raises the prospect of building a structured knowledge base (KB) directly
from an LM rather than from curated sources \citep{dong2014knowledgevault,vrandecic2014wikidata}.
Doing so is harder than answering a single factual question: a KB entry is a
\emph{complete set} of facts, so the model must decide not only what is true but
how many objects, possibly none, a subject and relation admit.

The LM-KBC~2026 shared task \citep{alivanistos2022prompting,kalo2023lmkbc,kalo2025lmkbc}
formalises this: given a subject $s$ and relation $r$, predict the complete object
set $\{o_1,\dots,o_k\}$, where $k$ may be zero, one, or many (Section~\ref{sec:task}).
Predictions are scored by macro precision, recall, and F\textsubscript{1}, with
alias matching for entities and a 5\% tolerance for numeric relations.

This is not single-answer probing. Unlike benchmarks such as LAMA
\citep{petroni2019lama}, which assume one gold object and reward ranking it highly,
the task demands the \emph{entire} set, and the empty set is a legitimate, frequent
answer: a living person has no recorded city of death, and an island country has no
land border. LM outputs are also stochastic, relations range from a single number
to hundreds of recipients, and the model must recognise when it does not know an
answer and \emph{abstain} rather than fabricate one.

The 2026 edition is strictly \emph{closed-book}: any open-weight model up to 32B
parameters, but no web search, retrieval, external corpus, or fine-tuning. This
forecloses the retrieval and tuning that strong entries in earlier editions relied
on \citep{zhang2023llmke,asai2024selfrag}, leaving parametric recall and prompt
design as the only levers.

We start from the evaluation metric rather than the model. Because
macro-F\textsubscript{1} scores an empty prediction against an empty gold set as
perfect, predicting nothing everywhere already attains $0.175$ relation-averaged
macro-F\textsubscript{1}, competitive with the official baseline ($0.273$) and
higher on the most null-heavy relations (Section~\ref{sec:task}). Points therefore
come not from answering everything, but from recalling the few numeric values and,
above all, from knowing when \emph{not} to answer. We make abstention a first-class
decision: for each null-heavy relation we sample several times and keep an object
only when the samples agree, collapsing to $\emptyset$ when the model is
inconsistent, while scope-grounded prompts and median aggregation handle the rest
(Figure~\ref{fig:pipeline}).

This paper makes three contributions. First, a metric analysis
(Section~\ref{sec:task}) shows that abstention is a high-value action: the
empty baseline already rivals the official baseline, which reframes the
task around \emph{when to answer}. Second, we build a per-relation pipeline
(Section~\ref{sec:method}) that grounds prompts in exact scopes and induces
\emph{calibrated abstention} via self-consistency voting, with no trained
confidence model; it lifts a weak 0.5B model from $0.173$ to $0.372$ on the
null-heavy relations. Third, the resulting open-weight system reaches $0.459$
relation-averaged macro-F\textsubscript{1} ($0.490$ micro) with Gemma-4-31B,
beating the official baseline on all six relations, while a 4-bit Qwen2.5-14B
reaches $0.416$ and shows that at this budget model scale dominates decode-time
self-consistency (Section~\ref{sec:analysis}).
