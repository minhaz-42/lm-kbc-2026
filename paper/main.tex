\begin{abstract}
We describe our system for the LM-KBC~2026 shared task on knowledge base
construction from language models (the 5th edition, hosted at the AKBC workshop,
EMNLP~2026). Given a subject and a relation, a system must return the
\emph{complete} set of object strings---which may be empty, a single value, or
hundreds of values---using only an open-weight model of at most 32B parameters,
with no retrieval, no external knowledge, and no fine-tuning. Our central
observation is that the macro-averaged metric rewards \emph{abstention}:
predicting the empty set for every validation instance already scores $0.175$
relation-averaged macro-F\textsubscript{1}, within reach of the official
baseline ($0.273$ relation-averaged). We therefore treat \emph{when to answer}
as a first-class decision, and build a per-relation pipeline that (i)~grounds the
prompt in each relation's exact scope, (ii)~induces calibrated abstention by
self-consistency voting across samples, and (iii)~aggregates the two numeric
relations by median. With Qwen2.5-14B-Instruct (14.7B parameters, run in 4-bit on
a single 16\,GB GPU) the system reaches \textbf{0.416} relation-averaged
macro-F\textsubscript{1} (\textbf{0.447} micro-averaged over all instances),
versus $0.273$/$0.284$ for the official baseline. We release all
code.\footnote{\url{https://github.com/ANON/lm-kbc-2026}}
\end{abstract}

\section{Introduction}
Pre-trained language models store substantial factual knowledge
\citep{petroni2019lama,roberts2020closedbook,alkhamissi2022review}, but turning
that knowledge into reliable knowledge-base (KB) entries is harder than
answering a single factual query. The LM-KBC~2026 shared task
\citep{lmkbc2025} frames KB construction as: given a subject entity $s$ and a
relation $r$, predict the complete set of object entities $\{o_1,\dots,o_k\}$,
where $k$ may be zero, one, or many. Unlike probing benchmarks that assume a
single answer \citep{petroni2019lama}, this setting makes no cardinality
assumption and is graded on string normalisation and alias matching rather than
entity disambiguation.

The 2026 edition imposes a strict \emph{closed-book} regime: any open-weight
model up to 32B total parameters, but no web search, no retrieval, no external
factual corpus, and no additional training. Multi-step inference and non-neural
post-processing are permitted. Submissions are scored by macro precision,
recall, and F\textsubscript{1}; numeric relations use a 5\% relative tolerance.

Our contributions are:
\begin{enumerate}[noitemsep,topsep=2pt,leftmargin=*]
  \item A metric analysis showing that abstention is a high-value action: the
  empty prediction alone scores $0.175$ relation-averaged
  macro-F\textsubscript{1} on validation, and matches or beats the official
  baseline on the most null-heavy relations (Section~\ref{sec:task}).
  \item A per-relation pipeline that grounds prompts in exact scopes and induces
  calibrated abstention via \emph{self-consistency voting}, with no trained
  confidence model. On the three null-heavy relations it lifts a weak 0.5B model
  from $0.173$ to $0.372$ macro-F\textsubscript{1} and still helps a strong 14B
  ($0.652\!\to\!0.666$); the gap reflects that the 14B is already
  well-calibrated (Sections~\ref{sec:method},~\ref{sec:ablations}).
  \item A reproducible open-weight system on a single commodity 16\,GB GPU that
  reaches $0.416$ relation-averaged macro-F\textsubscript{1}, beating the
  baseline on five of six relations, with all generation cached so the entire
  decode stage is re-tunable with no GPU (Sections~\ref{sec:setup}--\ref{sec:ablations}).
\end{enumerate}

\section{Task and Evaluation Analysis}
\label{sec:task}
\paragraph{Relations.} The task covers six relations (Table~\ref{tab:data}): two
numeric (\textsc{hasCapacity}, \textsc{hasArea}), one with very large object sets
(\textsc{awardWonBy}), and three string relations where an empty answer is
frequent (\textsc{countryLandBordersCountry}, \textsc{personHasCityOfDeath},
\textsc{companyTradesAtStockExchange}). Each relation has a precise scope---e.g.\
\emph{land} borders exclude maritime borders, \textsc{hasCapacity} uses the
highest published capacity, and \textsc{personHasCityOfDeath} is city-granular
and empty for living people---which we copy verbatim into the prompt.

\paragraph{Two averaging modes.} We report two summaries used throughout:
\emph{relation-averaged} macro-F\textsubscript{1} (mean of the six per-relation
macro-F\textsubscript{1}, the headline given the relation mix) and
\emph{micro-averaged} (over all instances, the figure the official
\texttt{evaluate.py} prints).

\paragraph{The metric makes abstention valuable.} Macro precision is $1$ when no
objects are predicted, and macro recall is $1$ when the gold set is empty; an
empty prediction against an empty gold set is therefore a perfect $F_1=1$. We
measured the consequence directly: predicting the empty set for \emph{every}
validation instance scores the per-relation macro-F\textsubscript{1} in the
``Empty'' column of Table~\ref{tab:results}, averaging $0.175$ over relations
($0.203$ micro). This already matches the official baseline's relation-averaged
$0.273$ on aggregate behaviour and \emph{exceeds} it on the two most null-heavy
relations (\textsc{personHasCityOfDeath} $0.450$ vs.\ $0.160$;
\textsc{companyTradesAtStockExchange} $0.350$ vs.\ $0.320$). This reframes the
task: gains come not from answering everything, but from (a)~recalling the two
numeric values and (b)~knowing precisely when \emph{not} to answer.

\section{Method: A Per-Relation Decoding Pipeline}
\label{sec:method}
Our pipeline (Figure~\ref{fig:pipeline}) maps each $(s,r)$ to a single chat
prompt, decodes one or more samples, and post-processes them into an answer set.
It has no trainable parameters and addresses the two analysis levers directly:
abstention (\emph{when to answer}) and numeric recall.

\paragraph{Scope-grounded prompts.} For each relation we write a system message
stating the task, the \emph{exact} ground-truth scope (copied from the official
relation definitions), and the expected answer shape; the model emits a single
JSON object \texttt{\{"answers":[\dots]\}} (Figure~\ref{fig:prompt}). This makes
the empty case unambiguous and parsing robust. Few-shot exemplars are drawn from
the training split; for the null-heavy relations we deliberately interleave empty
and non-empty exemplars so abstention is demonstrated, not merely instructed.

\begin{figure}[t]
\footnotesize\ttfamily
\fbox{\parbox{0.94\columnwidth}{%
SYS: You are a precise KB engine (closed book).\\
TASK: city where the subject died.\\
SCOPE: city granularity; empty if alive/unknown.\\
Reply only \{"answers":[...]\}; [] if unsure.\\[2pt]
U: Subject: Egbert Mulder \quad A: \{"answers":["Groningen"]\}\\
U: Subject: Dave Keon \quad\ A: \{"answers":[]\}\\
U: Subject: \textit{<query>} \quad\ A:
}}
\caption{Abbreviated prompt for a null-heavy relation. Mixed empty/non-empty
exemplars teach abstention; output is forced JSON. Even a 0.5B model emits valid
JSON on 100\% of instances.}
\label{fig:prompt}
\end{figure}

\paragraph{Calibrated abstention via self-consistency.} A single instruction to
``answer empty when unsure'' is not reliably obeyed: an unconstrained small model
names a death-city for living people and invents stock exchanges, driving
precision \emph{below} the empty baseline (Section~\ref{sec:ablations}). Instead,
for the three null-heavy relations we sample $N{=}3$ completions at temperature
$\tau{=}0.7$ and keep an object only if it appears in at least a fraction
$\theta$ of samples; for single-valued relations we abstain entirely if even the
top answer is below $\theta$ (Algorithm~\ref{alg:abstain}). When the model is
guessing, samples disagree and the prediction collapses to the empty
set---exactly where the metric rewards silence. This is a zero-parameter
confidence proxy, applied only to the three null-heavy relations and disabled for
\textsc{awardWonBy} (recall-bound) and the numeric relations.

\begin{algorithm}[t]
\small
\caption{\textsc{CalibratedAbstention}}
\label{alg:abstain}
\begin{algorithmic}[1]
\Require samples $S{=}\{s_1,\dots,s_N\}$, threshold $\theta$, \textit{multi}
\State $c[o] \gets$ \# samples whose parse contains object $o$
\If{\textit{multi}}
  \State \Return $\{o : c[o]/N \ge \theta\}$ \Comment{consensus set}
\Else
  \State $o^* \gets \arg\max_o c[o]$
  \State \Return $c[o^*]/N \ge \theta \;?\; \{o^*\} : \emptyset$
\EndIf
\end{algorithmic}
\end{algorithm}

\paragraph{Numeric aggregation.} For \textsc{hasCapacity} and \textsc{hasArea}
the answer is a single number graded within 5\% relative tolerance. We sample
$n{=}5$ completions and take the \emph{median} of the parsed numbers
\citep{wang2022selfconsistency}, as a robustness measure against outliers.

\paragraph{Robust parsing.} A relation-aware parser recovers the answer list from
noisy output (code fences, prose, trailing text), strips explicit empty markers,
extracts a single number for numeric relations (handling commas, units, scale
words), and de-duplicates string answers. Normalisation (lower-casing, diacritic
and punctuation removal) is byte-identical to the official evaluator; pushing
gold answers back through the parser scores a perfect $1.000$, confirming the
parser is lossless.

\section{Experimental Setup}
\label{sec:setup}
\paragraph{Model.} We use \textbf{Qwen2.5-14B-Instruct} \citep{qwen2024} (14.7B
parameters, within the 32B budget). Several nominally ``32B'' open models exceed
the cap (e.g.\ Qwen2.5-32B at 32.5B, Qwen3-32B at 32.8B) and are disqualified;
14.7B was the largest model we could run in 4-bit on the single 16\,GB GPU
available to us.

\paragraph{Inference and reproducibility.} Inference runs on one 16\,GB GPU
(NVIDIA T4) via 4-bit \texttt{bitsandbytes} (\texttt{nf4}) with \texttt{float16}
compute \citep{dettmers2023qlora}. We use 8-shot prompts \citep{brown2020gpt3}
for most relations (2-shot for \textsc{awardWonBy}). The submitted system uses
$\theta{=}0.5$ for the three null-heavy relations, $N{=}3$, $n{=}5$,
$\tau{=}0.7$. Quantisation only fits the hardware and does not change the counted
parameter budget. Generation (the expensive, GPU-bound step) writes a cache of
raw samples; all post-processing---parsing, abstention voting, median
aggregation, threshold choice---is a deterministic GPU-free function of that
cache, so every ablation below is computed from one generation pass and the whole
decode stage is reproducible without a GPU.

\section{Results}
\label{sec:results}
Our system scores \textbf{0.416} relation-averaged macro-F\textsubscript{1}
(\textbf{0.447} micro), versus $0.175$/$0.203$ for the empty baseline and
$0.273$/$0.284$ for the official baseline---a same-axis improvement on both
modes. Table~\ref{tab:results} gives the per-relation breakdown. We beat the
baseline on five of six relations; the exception is \textsc{hasCapacity}
($0.090$ vs.\ $0.100$), where exact capacities are essentially unknown to the
model and median aggregation is slightly worse than a single guess
(Section~\ref{sec:ablations}). The two strongest relations are
\textsc{countryLandBordersCountry} ($0.900$) and
\textsc{companyTradesAtStockExchange} ($0.616$); the high precision on
\textsc{personHasCityOfDeath} ($P{=}0.81$) is the direct signature of abstention.

\section{Ablations and Analysis}
\label{sec:ablations}
All ablations are decoded from the same cached samples.

\paragraph{Abstention rescues weak models, refines strong ones.}
Table~\ref{tab:ablation} isolates the abstention mechanism on the three
null-heavy relations. On a small, poorly-calibrated 0.5B model the effect is
dramatic: $0.173\!\to\!0.372$---without voting the model over-answers and falls
\emph{below} the empty baseline ($0.350$). On the 14B the single-sample output is
already above empty ($0.652$), so voting adds less ($0.652\!\to\!0.666$) but is
still positive. Crucially, abstention buys precision: on
\textsc{personHasCityOfDeath} it moves $P{=}0.77\!\to\!0.81\!\to\!0.89$ as
$\theta$ rises ($0\!\to\!0.5\!\to\!0.67$), trading a little recall
($0.52\!\to\!0.48$). The mechanism suppresses wrong guesses, not correct answers.

\paragraph{Numeric self-consistency is roughly neutral; the gap is
knowledge-bound.} Median aggregation over $n$ samples does \emph{not} reliably
help (Table~\ref{tab:numeric}): on \textsc{hasArea} it is non-monotonic
($0.300$ at $n{=}1$, $0.330$ at $n{=}5$), and on \textsc{hasCapacity} a single
sample ($0.100$) actually beats median-of-5 ($0.090$). Decode variance is not the
bottleneck---the model simply does not know exact capacities. Its predictions are
typically the right order of magnitude but outside the 5\% band (e.g.\ Spartan
Stadium: predicted $37{,}000$, gold $75{,}005$).

\paragraph{\textsc{awardWonBy} is recall-capped.} Gold sets average ${\sim}148$
recipients (max 641), but the 14B voluntarily enumerates only $\sim$11 names
(its outputs are \emph{not} truncated---it closes the JSON early), capping recall
near $11/148 \approx 0.07$. Listed names are often plausible-but-wrong
($P{=}0.36$). This relation is bounded by parametric recall and willingness to
enumerate, and is where a larger in-budget model or multi-step enumeration would
help most.

\section{Related Work}
\paragraph{LMs as knowledge bases.} \citet{petroni2019lama} framed factual recall
as single-answer cloze probing; \citet{roberts2020closedbook} measured
closed-book parametric capacity and \citet{alkhamissi2022review} survey the
line. Our task differs by being set-valued ($k{=}0$ to hundreds) and
alias-graded, with retrieval forbidden, so closed-book QA datasets such as
Natural Questions \citep{kwiatkowski2019nq} are a backdrop rather than the
setting.

\paragraph{The LM-KBC shared task.} Prior editions
\citep{lmkbc2022,lmkbc2023,lmkbc2024,lmkbc2025} progressed from masked-LM probing
and prompt engineering---often with retrieval or fine-tuning permitted and
per-relation prompt ensembling \citep{jiang2020lpaqa}---toward instruction-tuned
generative systems. The 2026 rules (closed-book, no fine-tuning, $\le$32B
open-weight) disallow the retrieval and tuning earlier entries relied on,
motivating a parametric-recall-plus-abstention design.

\paragraph{Calibration and selective prediction.} Abstaining from uncertain
predictions is the classic reject option \citep{elyaniv2010selective,
geifman2017selective}; neural calibration \citep{guo2017calibration} and
unanswerable-question QA \citep{rajpurkar2018squad2,kamath2020selectiveqa} are
its NLP forms, and LMs have some awareness of their own knowledge
\citep{kadavath2022know}. We use \emph{no} trained confidence head: sample
disagreement is a zero-parameter proxy, in a setting where the empty set is a
valid high-value answer rather than merely a reject option.

\paragraph{Self-consistency and sampling-based confidence.}
\citet{wang2022selfconsistency} majority-vote over sampled chains to pick one
answer; we instead use cross-sample agreement frequency as both a set-membership
filter and an abstention trigger, related to sampling-based hallucination and
uncertainty estimation \citep{manakul2023selfcheckgpt,kuhn2023semantic}. Our
contribution is the metric-driven application of these ideas to set-valued
closed-book KB construction.

\section{Conclusion}
We presented a closed-book KB-construction system whose design follows from a
metric analysis: abstention is valuable, numeric recall is the scarce resource,
and precise scope grounding curbs over- and under-prediction. With a single
14.7B open-weight model on commodity hardware it reaches $0.416$
relation-averaged macro-F\textsubscript{1} ($0.447$ micro), beating the official
baseline on five of six relations, and all post-processing is reproducible from a
cached generation pass.

\section*{Limitations}
The voting threshold $\theta$ is swept on the same validation split it is
evaluated on, so the reported per-relation optima are optimistic and not
held-out; we report no test-set numbers yet. Several margins are small relative
to plausible decoding noise: \textsc{awardWonBy} has only $n{=}10$ subjects, so
its $0.081$ is high-variance, and we did not measure run-to-run variance of the
stochastic decoding ($N{=}3$, $n{=}5$), so sub-$0.03$ deltas (e.g.\ the
\textsc{personHasCityOfDeath} $+0.030$) should be read as indicative. The system
is closed-book and inherits the base model's parametric coverage and recency
limits; it cannot recover facts the model never stored, which caps
\textsc{awardWonBy} recall and rare-venue numeric accuracy, and we were
constrained to a 14.7B model---larger in-budget models (up to 32B) would likely
help the numeric relations. Finally, the abstention advantage is a property of
this task's macro metric and the empty-as-valid-answer setting, and may not
transfer to micro-only or single-answer settings.

\section*{Ethics and Broader Impact}
Closed-book KB construction surfaces facts from model parameters, which may be
stale, biased, or hallucinated; predictions about people (e.g.\ place of death)
can be wrong and should not be treated as authoritative without verification. The
abstention mechanism partly mitigates this by emitting an empty answer rather
than a confident fabrication when the model is uncertain, functioning as a
lightweight factuality safeguard.
