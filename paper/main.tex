\begin{abstract}
We describe our system for the AKBC~2026 shared task on knowledge base
construction from language models. Given a subject and a relation, a system
must return the \emph{complete} set of object strings---which may be empty, a
single value, or hundreds of values---using only an open-weight model of at most
32B parameters, with no retrieval, no external knowledge, and no fine-tuning.
Our central observation is that the macro-averaged metric rewards
\emph{abstention}: predicting the empty set for every validation instance
already attains a macro-F\textsubscript{1} of $0.175$ (relation-averaged), which
exceeds the official baseline on the two most null-heavy relations. We therefore
treat \emph{when to answer} as a first-class modelling decision, and build a
per-relation prompting pipeline that (i)~states the exact ground-truth scope of
each relation, (ii)~induces calibrated abstention via self-consistency voting
across samples, and (iii)~stabilises the two numeric relations with median
self-consistency under the task's 5\% tolerance. With Qwen2.5-14B-Instruct
(a 14.7B open-weight model run in 4-bit on a single 16\,GB GPU) our system
reaches \textbf{0.416} relation-averaged macro-F\textsubscript{1} on validation
(\textbf{0.447} micro-averaged over all instances), versus the $0.175$ empty
baseline and the $0.284$ official baseline. We release all code.\footnote{\url{https://github.com/ANON/lm-kbc-2026}}
\end{abstract}

\section{Introduction}
Pre-trained language models store substantial factual knowledge
\citep{petroni2019lama,alkhamissi2022review}, but turning that knowledge into
reliable knowledge-base (KB) entries is harder than answering a single factual
query. The AKBC~2026 shared task \citep{lmkbc2025} frames KB construction as:
given a subject entity $s$ and a relation $r$, predict the complete set of
object entities $\{o_1,\dots,o_k\}$, where $k$ may be zero, one, or many. Unlike
probing benchmarks that assume a single answer \citep{petroni2019lama}, this
setting makes no cardinality assumption and is graded on string normalisation
and alias matching rather than entity disambiguation.

The 2026 edition imposes a strict \emph{closed-book} regime: any open-weight
model up to 32B total parameters, but no web search, no retrieval, no external
factual corpus, and no additional training. Multi-step inference and non-neural
post-processing are permitted. Submissions are scored by macro precision,
recall, and F\textsubscript{1}; numeric relations use a 5\% relative tolerance.

Our contributions are:
\begin{enumerate}[noitemsep,topsep=2pt]
  \item An analysis showing the macro metric makes \emph{abstention} a
  high-value action: the empty prediction alone scores $0.175$ relation-averaged
  macro-F\textsubscript{1} on validation and beats the official baseline on the
  two most null-heavy relations (Section~\ref{sec:task}).
  \item A per-relation pipeline that encodes each relation's exact scope and
  induces calibrated abstention by \emph{self-consistency voting}: it lifts the
  three null-heavy relations from $0.173$ to $0.372$ macro-F\textsubscript{1} on
  a small model, and remains beneficial on a strong one (Section~\ref{sec:method},
  \ref{sec:results}).
  \item A reproducible open-weight system that runs on a single commodity 16\,GB
  GPU and reaches $0.416$ relation-averaged macro-F\textsubscript{1}
  ($+0.241$ over the empty baseline), with all generation cached so
  post-processing is re-tunable without re-running the model
  (Sections~\ref{sec:setup}--\ref{sec:results}).
\end{enumerate}

\section{Task and Evaluation Analysis}
\label{sec:task}
\paragraph{Relations.} The task covers six relations (Table~\ref{tab:data}): two
numeric (\textsc{hasCapacity}, \textsc{hasArea}), one with very large object sets
(\textsc{awardWonBy}), and three string relations where an empty answer is
frequent (\textsc{countryLandBordersCountry}, \textsc{personHasCityOfDeath},
\textsc{companyTradesAtStockExchange}). Each relation has a precise scope---e.g.\
\emph{land} borders exclude maritime borders, \textsc{hasCapacity} uses the
highest published capacity, and \textsc{personHasCityOfDeath} is city-granular
and empty for living people.

\paragraph{The metric makes abstention valuable.} Macro precision is $1$ when no
objects are predicted, and macro recall is $1$ when the gold set is empty; an
empty prediction against an empty gold set is therefore a perfect $F_1=1$. We
measured the consequence directly: predicting the empty set for \emph{every}
validation instance yields the per-relation macro-F\textsubscript{1} in the
``Empty'' column of Table~\ref{tab:results}, averaging $0.175$ over relations
($0.203$ over all instances)---competitive with the $0.284$ official baseline,
and strictly better on \textsc{personHasCityOfDeath} ($0.450$) and
\textsc{companyTradesAtStockExchange} ($0.350$). This reframes the task: gains
come not from answering everything, but from (a)~recalling the two numeric
values and (b)~knowing precisely when \emph{not} to answer.

\section{System}
\label{sec:method}
Our pipeline maps each $(s,r)$ to a single chat prompt, decodes one or more
samples, and post-processes them into an answer set. It has no trainable
parameters.

\paragraph{Scope-grounded prompts.} For each relation we write a system message
stating the task, the \emph{exact} ground-truth scope (copied from the official
relation definitions), and the expected answer shape. The model emits a single
JSON object \texttt{\{"answers":[\dots]\}}, which makes the empty case
unambiguous and parsing robust. Even a 0.5B model follows this format on 100\%
of instances, so format compliance is never the bottleneck.

\paragraph{Calibrated abstention via self-consistency.} A single instruction to
``answer empty when unsure'' is not obeyed: an unconstrained model names a
death-city for living people and invents stock exchanges, driving precision
\emph{below} the empty baseline (Table~\ref{tab:ablation}). Instead, for the
three null-heavy relations we sample $N$ completions at temperature $\tau$ and
keep an object only if it appears in at least a fraction $\theta$ of samples;
for single-valued relations we abstain entirely if even the top answer is below
$\theta$. When the model is guessing, samples disagree and the prediction
collapses to the empty set---exactly where the metric rewards silence. This is
applied only to the three null-heavy relations (a per-relation flag); it is
disabled for \textsc{awardWonBy} (recall-bound) and the numeric relations.

\paragraph{Numeric self-consistency.} For \textsc{hasCapacity} and
\textsc{hasArea} the answer is a single number graded within 5\% relative
tolerance. We sample $n$ completions and take the \emph{median} of the parsed
numbers \citep{wang2022selfconsistency}, which is robust to outlier
hallucinations and well-matched to the tolerance metric.

\paragraph{Robust parsing.} A relation-aware parser recovers the answer list
from noisy output (code fences, prose, trailing text), strips explicit empty
markers, extracts a single number for numeric relations (handling commas, units,
scale words), and de-duplicates string answers. Normalisation (lower-casing,
diacritic and punctuation removal) is byte-identical to the official evaluator,
so internal de-duplication matches scoring.

\paragraph{Cached generation.} Generation (the expensive, GPU-bound step) writes
a cache of raw samples; all post-processing---parsing, abstention voting,
numeric aggregation, threshold choice---is a deterministic GPU-free function of
that cache. We therefore tune the entire decode stage offline without re-running
the model.

\section{Experimental Setup}
\label{sec:setup}
\paragraph{Model.} We use \textbf{Qwen2.5-14B-Instruct} (14.7B parameters, within
the 32B budget). We note that several nominally ``32B'' open models exceed the
cap (e.g.\ Qwen2.5-32B at 32.5B, Qwen3-32B at 32.8B) and are disqualified;
14.7B was the largest model we could run in 4-bit on the single 16\,GB GPU
available to us.

\paragraph{Inference.} Inference runs on a single 16\,GB GPU (NVIDIA T4) via
4-bit \texttt{bitsandbytes} (\texttt{nf4}) with \texttt{float16} compute
\citep{dettmers2023qlora}. We use 8-shot prompts for most relations (2-shot for
\textsc{awardWonBy}), with few-shot exemplars drawn from the training split and,
for null-heavy relations, deliberately interleaving empty and non-empty
exemplars. Numeric relations use $n{=}5$ samples at $\tau{=}0.7$; the three
null-heavy string relations use $N{=}3$ samples with $\theta$ swept post-hoc.
Quantisation is used only to fit the hardware and does not change the counted
parameter budget.

\section{Results}
\label{sec:results}

Our system scores \textbf{0.416} relation-averaged (\textbf{0.447} over all
instances), versus $0.175$/$0.203$ for the empty baseline and $0.284$ for the
official baseline. Two relations---\textsc{countryLandBordersCountry} ($0.900$)
and \textsc{companyTradesAtStockExchange} ($0.616$)---are strong; the deficits
are concentrated exactly where closed-book parametric recall is hardest: the
numeric relations and the very-large-set \textsc{awardWonBy}.

\paragraph{Ablation: abstention.} Table~\ref{tab:ablation} isolates the
abstention mechanism on the three null-heavy relations, decoded from the same
cached samples with voting on vs.\ off. On a small, poorly-calibrated model
(0.5B) the effect is dramatic: $0.173 \!\to\! 0.372$ relation-averaged
macro-F\textsubscript{1}---without abstention the model over-answers and falls
\emph{below} the empty baseline ($0.350$). On the strong 14B the model is
better-calibrated, so the gain is smaller ($0.409 \!\to\! 0.417$) but still
positive, and the high resulting precision on \textsc{personHasCityOfDeath}
($0.81$) confirms the mechanism is suppressing wrong guesses rather than
correct answers. Abstention thus rescues weak models and refines strong ones.

\paragraph{Ablation: numeric self-consistency.} For the numeric relations,
median-of-5 sampling improves over single greedy decoding by reducing the
influence of outlier hallucinations; \textsc{hasArea} reaches $0.330$, while
\textsc{hasCapacity} remains hard ($0.090$) because exact spectator capacities
are rarely recalled within the 5\% band.

\section{Analysis}
\paragraph{Where the points are.} The macro metric and the relation mix make
abstention and numeric recall the decisive factors. Our errors are dominated by
\emph{knowledge}, not format or parsing: at 0.5B every relation already emits
valid, correctly-shaped JSON, and the parser introduces no losses. The 14B's
remaining gaps are (i)~exact numbers it does not know (\textsc{hasCapacity}
predictions are typically the right order of magnitude but outside the 5\% band),
and (ii)~recall on \textsc{awardWonBy}, whose gold sets average ${\sim}148$
recipients: the model voluntarily enumerates only ${\sim}10$ (its outputs are
not truncated), capping recall near $0.05$. These are the relations where a
larger in-budget model, or multi-step enumeration, would help most.

\paragraph{Abstention calibration.} The optimal voting threshold tracks the
empty rate: \textsc{personHasCityOfDeath} (45\% empty) prefers more aggressive
abstention than \textsc{companyTradesAtStockExchange} or
\textsc{countryLandBordersCountry}, suggesting a per-relation threshold tuned on
validation.

\section{Conclusion}
We presented a closed-book KB-construction system whose design follows directly
from a metric analysis: abstention is valuable, numeric recall is the scarce
resource, and precise scope grounding curbs over- and under-prediction. With a
single 14.7B open-weight model on commodity hardware it reaches $0.416$
relation-averaged macro-F\textsubscript{1}, $+0.241$ over the empty baseline and
well above the official baseline, and all post-processing is reproducible from a
cached generation pass.

\section*{Limitations}
Our system is closed-book and inherits the parametric coverage and recency
limits of the base model; it cannot recover facts the model never stored, which
caps \textsc{awardWonBy} recall and rare-venue numeric accuracy. We were
constrained to a single 16\,GB GPU and thus to a 14.7B model in 4-bit; larger
in-budget models (up to 32B) would likely improve the numeric relations.
Abstention is induced by self-consistency rather than calibrated against an
explicit confidence model, so the answer/empty trade-off is not provably
optimal. Alias coverage depends on the evaluator's alias sets; non-English or
newly-coined aliases may be missed. All numbers are on the validation split; the
test distribution may differ.
