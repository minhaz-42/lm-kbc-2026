\begin{abstract}
We present our system for the LM-KBC~2026 shared task on knowledge base
construction from language models (5th edition, at the AKBC workshop,
EMNLP~2026). Given a subject and a relation, a system must return the
\emph{complete} object set---empty, single, or up to hundreds of values---using
only an open-weight model ($\le$32B parameters), with no retrieval, no external
knowledge, and no fine-tuning. Our central observation is that the macro
metric rewards \emph{abstention}: predicting the empty set everywhere already
scores $0.175$ relation-averaged macro-F\textsubscript{1}, near the official
baseline ($0.273$). We therefore treat \emph{when to answer} as a first-class
decision and build a per-relation pipeline that (i)~grounds prompts in each
relation's exact scope, (ii)~induces calibrated abstention by self-consistency
voting, and (iii)~aggregates numeric relations by median. With
Qwen2.5-14B-Instruct in 4-bit on a single 16\,GB GPU, the system reaches
$0.416$ relation-averaged macro-F\textsubscript{1} ($0.447$ micro), beating the
official baseline on five of six relations. All generation is cached, so the
entire decode stage is reproducible without a GPU. Code is
released.\footnote{\url{https://github.com/ANON/lm-kbc-2026}}
\end{abstract}

\section{Introduction}
Pre-trained language models (LMs) store substantial factual knowledge
\citep{petroni2019lama,roberts2020closedbook}, and a line of work probes and
extracts it \citep{jiang2020lpaqa,zhong2021optiprompt,alkhamissi2022review}.
Turning that knowledge into reliable knowledge-base (KB) entries---the goal of
KB construction and completion \citep{dong2014knowledgevault,vrandecic2014wikidata}---is
harder than answering one factual query. The LM-KBC shared task
\citep{alivanistos2022prompting,kalo2023lmkbc,kalo2025lmkbc} formalises this:
given a subject $s$ and relation $r$, predict the complete set of objects
$\{o_1,\dots,o_k\}$ with $k\in\{0,1,\dots\}$. Unlike single-answer probes such
as LAMA \citep{petroni2019lama}, it makes no cardinality assumption and grades
by string normalisation and alias matching, not entity disambiguation.

The 2026 edition is strictly \emph{closed-book}: any open-weight model up to
32B parameters, but no web search, no retrieval, no external corpus, and no
additional training. This rules out the retrieval and fine-tuning that strong
prior entries relied on \citep{zhang2023llmke,asai2024selfrag}, leaving
parametric recall and \emph{prompt design} as the only levers. Scoring is by
macro precision, recall, and F\textsubscript{1}; numeric relations use a 5\%
relative tolerance.

Our contributions are:
\begin{enumerate}[noitemsep,topsep=2pt,leftmargin=*]
  \item A metric analysis (Section~\ref{sec:task}) showing abstention is
  high-value: the empty prediction alone scores $0.175$ relation-averaged
  macro-F\textsubscript{1} and matches or beats the official baseline on the
  most null-heavy relations.
  \item A per-relation pipeline (Figure~\ref{fig:pipeline}, Section~\ref{sec:method})
  that grounds prompts in exact scopes and induces \emph{calibrated abstention}
  via self-consistency voting, with no trained confidence model: it lifts a weak
  0.5B model from $0.173$ to $0.372$ on the null-heavy relations and still helps
  a strong 14B.
  \item A reproducible open-weight system on a single 16\,GB GPU reaching
  $0.416$ relation-averaged macro-F\textsubscript{1}, beating the baseline on
  five of six relations, with cached generation enabling GPU-free decode-stage
  tuning (Sections~\ref{sec:setup}--\ref{sec:analysis}).
\end{enumerate}

\section{Background and Related Work}
\paragraph{LMs as knowledge bases.} \citet{petroni2019lama} cast factual recall
as cloze probing; follow-ups improved prompts \citep{jiang2020lpaqa,
shin2020autoprompt,zhong2021optiprompt}, measured closed-book capacity
\citep{roberts2020closedbook}, and questioned reliability
\citep{cao2021knowledgeable}. We target the set-valued, alias-graded variant
where the empty set is a valid answer.

\paragraph{The LM-KBC shared task.} Prior editions
\citep{alivanistos2022prompting,kalo2023lmkbc,kalo2024lmkbc,kalo2025lmkbc}
moved from masked-LM probing and prompt ensembling toward instruction-tuned
generative systems and, in some tracks, retrieval or fine-tuning
\citep{zhang2023llmke}. The 2026 closed-book, no-tuning, $\le$32B rules motivate
our parametric-recall-plus-abstention design.

\paragraph{Retrieval vs.\ closed book.} Retrieval augmentation
\citep{lewis2020rag,guu2020realm,asai2024selfrag} is the usual route to
knowledge-intensive accuracy and helps most exactly when parametric memory is
weak \citep{mallen2023whennot}; the 2026 rules forbid it, so we lean entirely
on parametric knowledge and decoding.

\paragraph{Self-consistency, calibration, and abstention.}
Self-consistency \citep{wang2022selfconsistency,chen2023universalsc} aggregates
sampled generations to select an answer. Abstaining when uncertain is the
classic reject option \citep{geifman2017selective} and its NLP forms---calibration
\citep{guo2017calibration}, unanswerable QA \citep{rajpurkar2018squad2},
selective QA \citep{cole2023selective}, and self-knowledge
\citep{kadavath2022know}. We use sample disagreement as a zero-parameter
confidence proxy \citep{kuhn2023semantic,manakul2023selfcheckgpt}, but in a
setting where the empty set is itself a high-value prediction.

\section{Task and Metric Analysis}
\label{sec:task}
The task has six relations (Table~\ref{tab:data}): two numeric
(\textsc{hasCapacity}, \textsc{hasArea}), one with very large object sets
(\textsc{awardWonBy}), and three string relations with frequent empty answers
(\textsc{countryLandBordersCountry}, \textsc{personHasCityOfDeath},
\textsc{companyTradesAtStockExchange}). Each has a precise scope (e.g.\ land-only
borders; city-granular death location; highest published capacity) which we copy
verbatim into the prompt. We report two summaries: \emph{relation-averaged}
macro-F\textsubscript{1} (mean of six per-relation scores) and
\emph{micro-averaged} (over all instances).

\paragraph{The metric makes abstention valuable.} Macro precision is $1$ when no
objects are predicted and recall is $1$ when the gold set is empty, so an empty
prediction against an empty gold set is a perfect $F_1$. Predicting the empty set
for \emph{every} validation instance therefore scores the ``Empty'' bars in
Figure~\ref{fig:bars}, averaging $0.175$ over relations ($0.203$ micro)---on par
with the official baseline's relation-averaged $0.273$ and \emph{above} it on the
two most null-heavy relations (\textsc{personHasCityOfDeath} $0.45$ vs.\ $0.16$;
\textsc{companyTradesAtStockExchange} $0.35$ vs.\ $0.32$). Gains thus come from
recalling the numeric values and from knowing when \emph{not} to answer.

\section{System}
\label{sec:method}
\paragraph{Architecture overview.} The pipeline (Figure~\ref{fig:pipeline}) maps
each $(s,r)$ to one chat prompt, decodes one or more samples, and aggregates them
per relation kind into an object set. It has no trainable parameters and targets
the two analysis levers: abstention and numeric recall.

\paragraph{Scope-grounded prompts.} Each relation's system message states the
task, the \emph{exact} ground-truth scope (copied from the official definitions),
and the answer shape; the model emits one JSON object
\texttt{\{"answers":[\dots]\}} (Figure~\ref{fig:prompt}). This makes the empty
case unambiguous. Few-shot exemplars come from the training split; for null-heavy
relations we interleave empty and non-empty exemplars so abstention is
demonstrated, not merely instructed. Even a 0.5B model emits valid JSON on 100\%
of instances, so format is never the bottleneck.

\paragraph{Calibrated abstention via self-consistency.} A bare instruction to
``answer empty when unsure'' is unreliable: an unconstrained small model names a
death-city for living people and invents stock exchanges, dropping precision
\emph{below} the empty baseline (Section~\ref{sec:analysis}). Instead, for the
three null-heavy relations we sample $N{=}3$ completions at temperature
$\tau{=}0.7$ and keep an object only if it appears in at least a fraction
$\theta$ of samples; single-valued relations abstain entirely if even the top
answer is below $\theta$ (Algorithm~\ref{alg:abstain}). When the model guesses,
samples disagree and the prediction collapses to $\emptyset$---where the metric
rewards silence. This is disabled for \textsc{awardWonBy} (recall-bound) and the
numeric relations.

\begin{algorithm}[t]
\small
\caption{\textsc{CalibratedAbstention}}
\label{alg:abstain}
\begin{algorithmic}[1]
\Require samples $S{=}\{s_1,\dots,s_N\}$, threshold $\theta$, \textit{multi}
\State $c[o] \gets \#\{s_i : o \in \textsc{parse}(s_i)\}$ for each object $o$
\If{\textit{multi}} \Return $\{o : c[o]/N \ge \theta\}$
\Else
  \State $o^* \gets \arg\max_o c[o]$;\ \ \Return $c[o^*]/N \ge \theta \,?\, \{o^*\} : \emptyset$
\EndIf
\end{algorithmic}
\end{algorithm}

\paragraph{Numeric aggregation.} \textsc{hasCapacity} and \textsc{hasArea} take a
single number graded within 5\%. We sample $n{=}5$ completions and take the
\emph{median} of the parsed numbers \citep{wang2022selfconsistency} as a
robustness measure.

\paragraph{Robust parsing.} A relation-aware parser recovers the answer list from
noisy output (code fences, prose), strips explicit empty markers, extracts one
number for numeric relations (handling commas, units, scale words), and
de-duplicates. Normalisation (lower-casing, diacritic/punctuation removal) is
byte-identical to the official evaluator; pushing gold answers back through the
parser scores $1.000$, confirming it is lossless.

\section{Experimental Setup}
\label{sec:setup}
\paragraph{Model.} We use \textbf{Qwen2.5-14B-Instruct} \citep{qwen2024}
(14.7B parameters, within budget). Several nominally ``32B'' models exceed the
cap (Qwen2.5-32B at 32.5B; Qwen3-32B at 32.8B) and are disqualified; 14.7B was
the largest model we could fit in 4-bit on our single 16\,GB GPU.

\paragraph{Inference and reproducibility.} Inference runs on one NVIDIA T4
(16\,GB) via 4-bit \texttt{bitsandbytes} (\texttt{nf4}), \texttt{float16}
compute \citep{dettmers2023qlora}. We use 8-shot prompts
\citep{brown2020gpt3} (2-shot for \textsc{awardWonBy}); the submitted system uses
$\theta{=}0.5$, $N{=}3$, $n{=}5$, $\tau{=}0.7$. Generation writes a cache of raw
samples; all post-processing---parsing, voting, median, threshold---is a
deterministic GPU-free function of that cache, so every ablation below comes from
one generation pass and is reproducible without a GPU.

\section{Results}
\label{sec:results}
The system scores \textbf{0.416} relation-averaged macro-F\textsubscript{1}
(\textbf{0.447} micro), versus $0.175$/$0.203$ (empty) and $0.273$/$0.284$
(official baseline)---a same-axis gain on both. Figure~\ref{fig:bars} and
Table~\ref{tab:results} give the per-relation picture: we beat the baseline on
five of six relations, the exception being \textsc{hasCapacity} ($0.09$ vs.\
$0.10$), where exact capacities are essentially unknown to the model. The
strongest relations are \textsc{countryLandBordersCountry} ($0.900$) and
\textsc{companyTradesAtStockExchange} ($0.616$); the high precision on
\textsc{personHasCityOfDeath} ($P{=}0.81$) is the signature of abstention.

\section{Analysis}
\label{sec:analysis}
All ablations are decoded from the same cached samples.

\paragraph{Abstention rescues weak models, refines strong ones.}
Table~\ref{tab:ablation} isolates abstention on the three null-heavy relations.
On a poorly-calibrated 0.5B model the effect is dramatic
($0.173\!\to\!0.372$)---without voting it over-answers and falls \emph{below} the
empty baseline ($0.350$). The 14B is already above empty without voting
($0.652$), so voting adds less ($0.652\!\to\!0.666$) but remains positive.
Abstention buys precision: on \textsc{personHasCityOfDeath} it moves
$P{=}0.77\!\to\!0.81\!\to\!0.89$ as $\theta$ rises, trading a little recall---it
suppresses wrong guesses, not correct answers.

\paragraph{Threshold tracks the empty rate; numeric voting is neutral.}
Figure~\ref{fig:ablate} (left) sweeps $\theta$: the most null-heavy relation,
\textsc{personHasCityOfDeath} (45\% empty), peaks at a \emph{lower} $\theta$,
while the others tolerate aggressive voting---arguing for per-relation
thresholds. Figure~\ref{fig:ablate} (right) varies the number of numeric
samples: median aggregation is non-monotonic on \textsc{hasArea} and actually
slightly \emph{hurts} \textsc{hasCapacity} (single sample $0.10$ vs.\ median-5
$0.09$). Decode variance is not the bottleneck---the gap is knowledge-bound; the
model's capacity guesses are the right order of magnitude but outside the 5\%
band (e.g.\ Spartan Stadium: predicted $37{,}000$, gold $75{,}005$).

\paragraph{\textsc{awardWonBy} is recall-capped.} Gold sets average ${\sim}148$
recipients (max 641) but the 14B enumerates only ${\sim}11$ names---its outputs
are \emph{not} truncated (it closes the JSON early)---capping recall near
$11/148\approx0.07$. Listed names are often plausible-but-wrong ($P{=}0.36$).
This relation is bounded by parametric recall and willingness to enumerate, where
a larger in-budget model or multi-step decomposition would help most.

\section{Conclusion}
Our system's design follows from a metric analysis: abstention is valuable,
numeric recall is scarce, and scope grounding curbs over- and under-prediction.
With a single 14.7B open-weight model on commodity hardware it reaches $0.416$
relation-averaged macro-F\textsubscript{1} ($0.447$ micro), beating the official
baseline on five of six relations, and is fully reproducible from a cached
generation pass.

\section*{Limitations}
The voting threshold $\theta$ is swept on the same validation split it is
evaluated on, so per-relation optima are optimistic and not held-out; we report
no test numbers yet. Several margins are within plausible decoding noise:
\textsc{awardWonBy} has only $n{=}10$ subjects, and we did not measure
run-to-run variance of the stochastic decoding ($N{=}3$, $n{=}5$), so
sub-$0.03$ deltas (e.g.\ the \textsc{personHasCityOfDeath} $+0.03$) are
indicative only. Being closed-book, the system inherits the base model's
coverage and recency limits and cannot recover facts it never stored, which caps
\textsc{awardWonBy} recall and rare-venue numeric accuracy; a larger in-budget
model (up to 32B) would likely help the numeric relations. Finally, the
abstention advantage is a property of this task's macro metric and the
empty-as-valid-answer setting, and may not transfer to single-answer or
micro-only settings.

\section*{Ethics and Generative-AI Declaration}
Closed-book KB construction surfaces facts from model parameters that may be
stale, biased, or hallucinated; predictions about people (e.g.\ place of death)
can be wrong and should not be treated as authoritative without verification. The
abstention mechanism partly mitigates this by emitting an empty answer rather
than a confident fabrication when the model is uncertain. The only generative-AI
component is the open-weight LM used for the predictions themselves, as the task
requires; no proprietary assistant was used to produce results.
